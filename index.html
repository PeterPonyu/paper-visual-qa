The object

Operators regenerate local figure trees from the figures-src chain, then validate hashes.

A leak scan looks for internal codenames and path crumbs in rendered text. QA closure is not a science gate.

What is measured

  • Per-tree hashes in the local QA tree
  • Leak-scan report on rendered text
  • Contact sheets for side-by-side visual pass

Protocol

  • Regenerate only from the documented figure source chain.
  • Run the hash validator.
  • Refresh contact sheets if the PDFs changed. Do not treat QA done-ness as a science pass.

Measurements

Blast radius

Local QA trees and contact sheets. Not canonical science tables. Not frozen archive bytes.

Safe to rerun

Yes for QA regeneration on the documented paths.

Non-goal

Not a claim-bearing warehouse. Not a substitute for hostile number review.
